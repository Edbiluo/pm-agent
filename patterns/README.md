# EvoMap 云端共享 Pattern 库

> 同类技术问题仅需一人解决一次，全员低 Token 复用。

## 目录分类

| 目录 | 中文含义 | 范围 |
|------|----------|------|
| `01-env/` | 环境问题 | PowerShell、CMD、Node、Python、代理、SSL、网络报错 |
| `02-uniapp-cross/` | UniApp 跨端 | RTL、阿语适配、谷歌订阅、支付、打包、图标、推送 |
| `03-data-collection/` | 数据采集 | 反爬、定时任务、时序库、Excel、429 限流、代理错误 |
| `04-general-dev/` | 通用开发 | 前端样式、数据库、接口、跨域、服务集成 |

需要新分类时可创建 `05-{name}/` 目录。

## Pattern 文件格式（固定不可修改）

每条 Pattern 为独立 `.md` 文件，存放于对应分类目录下：

```
---
【标签】多维度检索标签，逗号分隔
【场景】一句话界定适用范围
【问题】精简问题描述
【根因】1~2 行核心原因
【标准解法】可直接复制执行的方案/代码/命令/配置
【避坑要点】关键限制、兼容问题、环境约束
【复用提示】AI 快速调用精简规则
---
```

## index.json 索引格式

```json
[
  {
    "tags": ["关键词1", "关键词2"],
    "scene": "适用场景",
    "filePath": "分类目录/对应文件.md",
    "updateTime": "YYYY-MM-DD"
  }
]
```

## 贡献规则

1. 解决全新问题后按格式生成 Pattern 文件
2. 同步更新 `index.json` 索引
3. Commit 后 push 到 main 分支
4. 已有方案优化：对比旧 Pattern，仅更新差异部分
5. 失效方案：标记废弃或删除，同步清理索引
